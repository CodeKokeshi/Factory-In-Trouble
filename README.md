# Machines Phaser

Phaser 3 starter project using Vite and plain JavaScript.

## Prerequisites

- Node.js 18+
- npm 9+

## Scripts

- `npm run dev` - start local dev server
- `npm run build` - production build
- `npm run preview` - preview production build

## Quick Start

```bash
npm install
npm run dev
```

## Notes

- The starter scene includes keyboard and basic gamepad navigation.
- Core game entry is in `src/main.js`.
- Start adding gameplay in `src/scenes/GameScene.js`.
